# 集装箱办公楼交互网页

基于校正后的 Blender 工程制作，外观橙色、室内暖白。网页使用 Three.js，手机优先，支持电脑浏览。

源码仓库：https://github.com/gmate-sg/container-office-3d

- 上帝视角：旋转、平移、滚轮或双指缩放，无人为缩放范围限制。
- 人物漫游：第一／第三人称、触屏摇杆、转向、跳跃、碰撞和楼梯通行。
- 手机横屏：顶部“横屏”按钮尝试全屏并锁定方向。浏览器不支持方向锁定时，可手动横置手机；人物横屏界面隐藏侧栏，保留游戏操作按钮。
- 人物状态同样支持滚轮／双指光学缩放，无人为缩放上下限，缩放不改变人物实际位置。
- 门柜交互：8 扇房门、42 扇柜门可开合。
- 尺寸：上帝视角显示建筑尺寸；人物状态显示空间范围、层高和对准构件的尺寸。图纸值与模型量取值分开标明。
- 图纸说明：保留中英文技术说明和设备图例。
- 效果图：7 张原生实景渲染图，2560 × 1440。

## 运行和构建

```sh
npm install
npm run dev
npm run build
npm run build:pages
```

开发地址由 Vite 输出。构建结果位于 `dist`，可部署到普通静态网站服务器。

GitHub Pages 使用 `docs` 目录中的预构建版本。运行 `npm run build:pages` 更新 `docs` 后提交；仓库的 Pages 发布源选择 `main` 分支、`/docs` 目录。本版本使用相对资源地址，适配 `用户名.github.io/仓库名/` 子路径。

`src/main.js` 管理展示、材质、视角和菜单，`src/walker.js` 管理人物操作与碰撞，`src/dimensions.js` 管理尺寸。模型、碰撞数据、环境光和效果图位于 `public/assets`。

模型使用 glTF Meshopt 几何压缩及 WebP 纹理；浏览器运行时不依赖外部 CDN。环境与部分材质／家具来源为 Poly Haven，授权为 [CC0](https://polyhaven.com/license)。图纸未标注的设备型号、软装和场地布置属于表现方案，说明保存在网页中。
